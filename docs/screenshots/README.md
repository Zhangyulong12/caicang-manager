## 拍摄与检查

1. 从README的快速启动进入系统，确认API可访问、当前商家正确。展示用数据应能与真实API查询一致；本任务不为截图新建或修改业务数据。
2. Web使用系统截图工具截取页面主体；Android使用手机系统截图功能。只为截图查看现有单据，不要重复确认收货或发货。
3. 截图前收起账户菜单、开发者工具和日志。避免包含真实邮箱、电话、地址、运单号、Token、环境变量或签名资料；必要时在本机遮盖敏感区域，不改变业务数值和状态。
4. 按上表命名放入本目录；不要直接上传忽略目录中的原始验收截图，它们可能含账号资料。
5. 确认图片内容和脱敏后，在根README中取消对应图片行的HTML注释，将表格中“尚未补图”的说明同步改为实际状态。未拍摄的图片行继续留在注释中。
6. 用Markdown预览检查图片比例、可读性与相对路径。补图属于后续改动，按用户确认的范围提交；本任务不自动上传。
